# ☄️ Sobre Mim
Meu nome é Vanderson Paulo e sou Desenvolvedor de Software Full Stack, graduado em Sistemas de Informação.

Gosto de programar e, principalmente, de entender como as coisas funcionam por trás do código. Trabalho principalmente com JavaScript, TypeScript, React, Next.js e Node.js, desenvolvendo aplicações web, APIs e sistemas completos.

Atualmente, também venho aprofundando meus conhecimentos em arquitetura de software, bancos de dados, Docker, Linux, infraestrutura e boas práticas de desenvolvimento. Gosto de aprender através de projetos reais, colocando o conhecimento em prática e buscando entender não apenas como fazer algo, mas por que aquela solução faz sentido.

Aqui no GitHub você encontrará projetos que desenvolvi ao longo da minha trajetória, desde sistemas acadêmicos e projetos profissionais até experimentos que utilizo para aprender e explorar novas tecnologias.
